# dannyegi — Portfolio

Website portfolio statis dengan HTML, CSS, dan JavaScript vanilla.

## Struktur
- `index.html` — kerangka dan konten halaman.
- `css/style.css` — semua styling, layout responsif, dan animasi.
- `js/main.js` — logika/interaksi JavaScript.
- `assets/images/` — tempat gambar proyek, foto, atau thumbnail.
- `assets/fonts/` — opsional jika nanti memakai font lokal.
- `README.md` — catatan proyek.

## Menjalankan lokal
Buka `index.html` di browser. Untuk pengembangan lebih nyaman, gunakan ekstensi Live Server di editor kode.

## Deploy gratis ke GitHub Pages
1. Unggah isi folder proyek ke repository GitHub.
2. Pastikan `index.html` berada di root repository.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu simpan.
5. Tunggu proses deploy selesai. Setelah perubahan di-commit, GitHub Pages akan deploy ulang otomatis.

Catatan: font Inter dimuat dari Google Fonts, sehingga koneksi internet diperlukan agar font tersebut tampil.
